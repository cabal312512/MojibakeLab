## Mojibake Lab 0.1.0

A compact, offline encoding forensics tool. Repair common mojibake, compare candidates, and inspect the exact byte/text conversion path. English by default, with 简体中文 and 日本語. Light interface, no accounts, telemetry, updates, or AI service calls.

### Choose a download

| System | Download | Use |
| --- | --- | --- |
| Windows 10/11 x64 | `windows-x64-portable.exe` | Single executable; no installation |

Full filenames start with `MojibakeLab-0.1.0-`. `SHA256SUMS.txt` contains hashes for every download. GitHub also provides automatic source archives below the assets.

### Single-file Windows edition

Only the EXE is needed to launch on a system with **Microsoft Edge WebView2 Runtime already installed**. The webview runtime is not embedded or silently downloaded. Settings and cache are created in `runtime-data` beside the executable, so keep it in a writable folder. The MIT and third-party notices are embedded; click **MIT** in the footer to read them offline.

### Notes

- Windows downloads are unsigned. macOS builds have an ad-hoc signature but are not notarized; the operating system may require confirmation before opening them.
- macOS data is stored in `~/Library/Application Support/MojibakeLab`; Linux uses `$XDG_DATA_HOME/mojibake-lab` or `~/.local/share/mojibake-lab`. `MOJIBAKE_DATA_DIR` overrides the location.
- Export writes a new UTF-8 file and refuses to overwrite existing files. Large inputs are sampled for analysis and checked fully while exporting.
- Source launcher renamed to **MojibakeLab.cmd**.
- MIT licensed. Local interactive checks cover Windows; cross-platform CI verifies builds and automated tests.
